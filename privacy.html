Social Uploader: Privacy policy

Last updated: October 2026

Back to the home page

What this tool is

Social Uploader is a personal automation tool that runs on its owner's own computer or server. It is not distributed to other people. The only person who signs in to it and uses it is its owner.

Google user data the tool accesses

When its owner signs in with Google and gives permission, the tool can:

  • YouTube: upload videos to the owner's own channel, set their title, description, tags and publish time, and add them to one of the owner's own playlists.
  • Google Drive: read the video files in a folder the owner chooses, and move them to the computer that runs the tool.

How the data is used

The data is used only for the purposes above: publishing the owner's own videos. It is not used for advertising, profiling, analytics, or training of any model, and no person reads it.

Storage

The sign-in tokens and the video files are kept only in files on the owner's own computer or server. They are not stored on any other service run by the owner of this tool. Videos are sent only to the places the owner chooses in each case (YouTube, Facebook and Instagram), at the owner's request.

Sharing

Google user data is not sold, shared, or transferred to any third party.

Google API Services User Data Policy

Social Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The owner can stop the tool's access at any time at myaccount.google.com/permissions, and can delete the stored tokens and video files from the computer or server that runs the tool.
